# Интерактивный прототип ReviewScope

Двенадцать синтетических отзывов позволяют исследовать одну проблему в одной точке: почему одни фразы описывают задержку выдачи, а другие говорят о приготовлении или прямо отрицают ожидание. От выбора пары можно перейти к её исходным текстам, затем сравнить два периода.

## Запуск

Из корня рабочей копии с PR-03, с Node.js 24 и npm:

```sh
cd prototypes/reviewscope-ui
npm ci
npm run dev
```

Откройте <http://127.0.0.1:5173/>. Сервер слушает только локальный адрес. Для остановки нажмите Ctrl+C. Проверено с Node.js 24.14.1 и npm 11.11.0. После установки пакетов для работы прототипа достаточно локального сервера.

В той же папке:

```sh
npm run lint
npm test
npm run build
```

Сборка включает проверку TypeScript и пишет статические файлы в `dist/`. Тесты используют встроенный в Node.js модуль и проверяют прямые рёбра и состав числителей и знаменателей.

## Семь шагов для приёмки

1. На главной откройте «Возможности». Под схемой Евразии есть подпись «Демонстрационная схема». Вернитесь по логотипу и нажмите «Исследовать демо». Откроются сентябрьские отзывы и пара #01–#02.
2. Нажмите линию #02–#03. В панели «Почему они связаны» сопоставьте жалобу и отрицание. Выберите узел #01, затем сравнение с #03. Общий сосед #02 есть, прямого ребра между выбранными отзывами нет.
3. В «Списке связей» выберите #02–#05 и прочитайте дословный повтор. Введите в поиск «нет-такой-фразы», затем сбросьте фильтры. Выберите позицию «Неоднозначно» и прочитайте, достаточно ли в отзыве сведений об этапе ожидания.
4. Откройте «Изменения». Переключите сентябрь на октябрь и проверьте исходные строки. В сентябре 3 жалобы из 6 текстовых отзывов, в октябре 1 из 5. Запись #12 с одной оценкой показана отдельно. Нажмите на строку, проверьте выбранный отзыв и вернитесь кнопкой браузера.
5. В разделе «Импорт» переключите пустую форму, прогресс и ошибку. В «Отчёте» смените период. Выбор файла и скачивание PDF недоступны, меняются только состояния предварительного просмотра.
6. На телефоне или при ширине 390 px откройте меню, выберите «Исследование», нажмите на отзыв и прокрутите до его оснований. Оцените, легко ли вернуться к списку и увидеть, какая пара выбрана.
7. В Firefox пройдите выбор пары клавишами Tab и Enter. Включите «Матовые панели» внизу страницы и сравните с обычным режимом. При системной настройке уменьшения движения переходы отключаются автоматически.

## Основания и границы

[Отзывы, метки и прямые рёбра](src/fixture.ts) заданы вручную. [Подсчёт](src/analysis.ts) включает в знаменатель каждую запись с текстом один раз. В числитель попадает только жалоба на выдачу готового заказа. У двух совпадающих текстов #02 и #05 разные ID. Изменение с 50% до 20% составляет −30 процентных пунктов в этих демонстрационных данных.

[Схема Евразии](public/eurasia.svg) построена из полигонов Европы и Азии Natural Earth 1:110m v5.1.2. Береговые линии упрощены для маленького экрана. Две световые метки иллюстрируют композицию и не обозначают клиентов. Геометрия хранится локально, подписи используют системные шрифты. [Исходные полигоны Natural Earth](https://github.com/nvkelso/natural-earth-vector/blob/v5.1.2/geojson/ne_110m_admin_0_countries.geojson) · [Условия использования геометрии](https://www.naturalearthdata.com/about/terms-of-use/)

Прототип работает на React, TypeScript и Vite, без подключения к Python, моделям, клиентским файлам и внешним API. Отправка отчёта и сохранение выбора между перезапусками вне объёма. [Статус ручной приёмки](../../docs/development/pr03-ux-handoff.md)
