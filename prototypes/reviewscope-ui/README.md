# ReviewScope · интерактивный прототип

Откройте исходную фразу, проследите за одной проблемой в нескольких точках и проверьте, как получилась разница между периодами. На всех экранах используются синтетические отзывы.

## Локальный запуск

В рабочей копии PR #5 с Node.js 24 и npm выполните

```sh
cd prototypes/reviewscope-ui
npm ci
npm run build
npx vite preview --host 127.0.0.1 --port 5175 --strictPort
```

Откройте <http://127.0.0.1:5175/>. Vite слушает loopback. Если порт занят другим приложением, можно выбрать свободный через параметр `--port`.

## Проверить v9

1. Откройте `#home`. Поле выходит за края трёх карточек. Даже в середине точки слегка смещены, а у края их свет растворяется в фоне. Наведите на #02 и перетащите карточку за цитату. Следующий щелчок открывает #02. На сенсорном экране первое касание показывает цитату, второе открывает отзыв.
2. Прокрутите до карты. Остановитесь на полпути и прокрутите немного обратно. Те же частицы образуют Евразию, а буквы первого заголовка занимают места во втором. Прямая ссылка на собранную карту — `#features`.
3. Выберите «Моя сеть». В сентябре общий результат — 3/10. Переключите период на октябрь и выберите «Мыс». Откройте «Состав расчёта» в карточке показателя и проверьте три пропуска. Escape возвращает фокус. В режиме сравнения панель содержит обе выборки.
4. Продолжите прокрутку. Буквы собираются в третий заголовок. Частицы карты обрисовывают скруглённые края трёх карточек отдельного примера. В `#how` наведите на «Проверить смысл» или перейдите к карточке клавишей Tab. На обороте видны две исходные фразы и пояснение. Рамка сохраняет размер. Щелчок или Enter открывает исследование, Escape возвращает лицевую сторону. На телефоне первое касание открывает оборот, второе следует ссылке.
5. Повторите проход вверх. Проверьте выбранную компанию, период и положение карточек. На узком или низком экране разделы читаются в потоке. Системное уменьшение движения показывает готовые поля.

## Проверки и запись

```sh
npm run lint
npm run typecheck
npm test
npm run build
npx playwright install --with-deps chromium firefox
npm run test:browser
BROWSER=firefox npm run test:browser
npm run capture:ux
```

Запись открывает временный production preview. Первый аргумент `capture:ux` задаёт каталог для WebM, PNG, измерений и `verification.md`. Необязательный второй аргумент — каталог production-сборки v8 для сравнения. Для самостоятельного просмотра сборки выполните `npx vite preview --host 127.0.0.1 --port 5175 --strictPort`.

Frontend-проверка прикрепляет артефакт **reviewscope-pr03-ux-v9**. В нём два ролика — полный проход вниз и обратно и отдельная проверка взаимодействий. PNG включают кадры четвертей обоих переходов, три состояния карточки метода, карту на нижней яркости выбранной компании и мобильную панель. [Проверки Draft PR #5](https://github.com/zinverno/reviewscope/pull/5/checks)

## Данные и геометрия

- [Исследование](src/fixture.ts) содержит 12 отзывов. Каждый ID с текстом входит в знаменатель один раз. #02 и #05 имеют разные ID с одинаковым текстом. В числитель входят жалобы на выдачу. Отрицания, неопределённость и жалобы на приготовление остаются в знаменателе. Пустая запись показана отдельно. [Правило подсчёта](src/analysis.ts)
- [Снимки четырёх вымышленных точек](src/network.ts) отделены от исследования. Сеть объединяет записи трёх собственных точек. «Луч» участвует в сравнении. Маркеры и состав расчёта используют один выбор.
- [Локальный контур Евразии](src/eurasia.svg) получен из Natural Earth 1:110m v5.1.2. Контур определяет центры кругов. Их положение на карте и положение маркеров вычисляются в одной проекции с общим кадром `mapFrame`. [Растровый рисунок поля](src/pointTexture.ts) задаёт центры и свет для трёх сцен. Те же частицы собираются в карту и окрашиваются для выбранных точек. Геометрия и шрифты доступны офлайн. [Исходные полигоны](https://github.com/nvkelso/natural-earth-vector/blob/v5.1.2/geojson/ne_110m_admin_0_countries.geojson) · [Условия использования](https://www.naturalearthdata.com/about/terms-of-use/)
- Смена лиц реализована средствами HTML и CSS по визуальному референсу владельца. [Карточка gharsh11032000 на Uiverse](https://uiverse.io/gharsh11032000/tricky-cheetah-78)

Импорт, клиентский отчёт и PDF показывают будущие состояния. Вычисления и примеры работают локально на фиксированных данных. [Передача владельцу на приёмку](../../docs/development/pr03-ux-handoff.md)
