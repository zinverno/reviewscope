# ReviewScope · интерактивный прототип

Откройте исходную фразу, проследите за одной проблемой в нескольких точках и проверьте, как получилась разница между периодами. На всех экранах используются синтетические отзывы.

## Локальный запуск

В рабочей копии PR #5 с Node.js 24 и npm выполните

```sh
cd prototypes/reviewscope-ui
npm ci
npm run dev
```

Откройте <http://127.0.0.1:5173/>. Vite слушает loopback. Если порт занят другим приложением, можно выбрать свободный через параметр `--port`.

## Семь шагов ручной приёмки

1. На главной наведите указатель на #02 или выберите карточку клавишей Tab. Номер и статус сменятся полной цитатой на той же площади. Посмотрите, видны ли точки за словами. Нажмите Escape, чтобы вернуть лицевую сторону.
2. Потяните #02 за середину цитаты. Участок видимого за стеклом поля меняется, линии следуют за границами. Отпустите карточку, затем щёлкните по ней. Откроется именно #02. Вернитесь кнопкой браузера. Начните новый перенос и нажмите Escape до отпускания, чтобы отменить его.
3. На телефоне коснитесь карточки один раз для чтения, второй раз для входа. Стрелка открывает отзыв сразу. Проведите пальцем по цитате для прокрутки страницы. Включите «Перемещение», подвиньте карточку за цитату или кнопками со стрелками и нажмите «Готово». «Сбросить расположение» возвращает все карточки.
4. Сравните главную с референсом: за карточками — мелкая ровная сетка, заголовок свободен от россыпи. Медленно прокрутите от отзывов к карте и обратно, останавливаясь на каждой четверти пути, затем сделайте 5–10 коротких реверсов у конца сборки. Начало перехода — за одну высоту поля до верхней границы секции карты, конец — когда эта граница достигнет верха окна. В окне 1440×900 это 0, 225, 450, 675 и 900 CSS-пикселей. Остановитесь на половине и измените ширину окна. На готовой карте побудьте 6–8 секунд: ореолы плавно дышат, центры кругов неподвижны. Внутри сцены география остаётся собранной. Рассмотрите целые кружки у берегов и точки за панелью показателя.
5. Выбирайте точки только по маркерам карты: «Арка», «Линия», «Мыс» и «Луч» доступны касанием, мышью и с клавиатуры (Tab, Enter/Space). В «Одной точке» выберите «Арка» на сентябрь (2/3). В «Моей сети» раскройте состав «Вся сеть» (3/10) или отдельной точки и вернитесь кнопкой «← К итогу всей сети». У октябрьского «Мыса» три записи без текста и статус «Нет данных». В «Сравнении» выберите свою точку и «Луч», раскройте обе выборки.
6. Под картой выберите «Проверить смысл» и оставьте сцену открытой. Шаг сохраняет выбор. Сопоставьте жалобу #02 с отрицанием #03. Через «Сравнить изменения» откройте два периода. В сентябре 3/6, в октябре 1/5, разница −30 п. п. Откройте исходные строки и вернитесь через Back.
7. В исследовании проверьте отсутствие прямой связи #01–#03 и повтор текста #02–#05. Оставьте выбранную пару и фильтр, перейдите в «Отчёт» и вернитесь. Повторите маршрут с клавиатурой, при масштабе 200%, с системным уменьшением движения и переключателем «Матовые панели» внизу страницы.

## Проверки и видеозапись

```sh
npm run lint
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:browser
npm run capture:ux
```

Браузерные тесты запускают временный Vite-сервер. Для тестового Firefox задайте `BROWSER=firefox` и при необходимости `BROWSER_PATH` с путём к исполняемому файлу. После сборки команда `capture:ux` открывает локальный production preview, записывает действия в Chromium, сохраняет сопоставимые кадры до/после и профиль wheel-прокрутки. Выводится путь к каталогу с тремя WebM, PNG и `frame-profile.json`. Для своего пути передайте имя каталога через `npm run capture:ux -- <каталог>`, а для сравнения с принятой версией — и каталог её сборки вторым аргументом.

В запуске **ReviewScope frontend** для PR #5 доступен архив **reviewscope-pr03-ux-v4**. Первый ролик показывает нативную прокрутку вниз/вверх с короткими реверсами, второй — смену лица, перенос за цитату и вход в отзыв, третий — неподвижную карту со свечением. Профиль `frame-profile.json` фиксирует обновления геометрии, пропуски и интервалы; видео записано в 25 кадр/с. [Проверки и вложения PR #5](https://github.com/zinverno/reviewscope/pull/5/checks)

## Данные и геометрия

- [Исследование](src/fixture.ts) содержит 12 отзывов. Каждый ID с текстом входит в знаменатель один раз. #02 и #05 имеют разные ID с одинаковым текстом. В числитель входят жалобы на выдачу. Отрицания, неопределённость и жалобы на приготовление остаются в знаменателе. Пустая запись показана отдельно. [Правило подсчёта](src/analysis.ts)
- [Снимки четырёх вымышленных точек](src/network.ts) отделены от исследования. Сеть объединяет записи трёх собственных точек. «Луч» участвует в сравнении. Маркеры и состав расчёта используют один выбор.
- [Локальный контур Евразии](src/eurasia.svg) получен из Natural Earth 1:110m v5.1.2. Контур определяет центры кругов. Их положение на карте и положение маркеров вычисляются в одной проекции с общим кадром `mapFrame`. [Растровый рисунок поля](src/pointTexture.ts) задаёт регулярную hero-сетку, целые ядра и мягкий ореол; те же частицы собираются в карту. Геометрия и шрифты доступны офлайн. [Исходные полигоны](https://github.com/nvkelso/natural-earth-vector/blob/v5.1.2/geojson/ne_110m_admin_0_countries.geojson) · [Условия использования](https://www.naturalearthdata.com/about/terms-of-use/)
- Смена лиц реализована средствами HTML и CSS по визуальному референсу владельца. [Карточка gharsh11032000 на Uiverse](https://uiverse.io/gharsh11032000/tricky-cheetah-78)

Импорт, клиентский отчёт и PDF показывают будущие состояния. Вычисления и примеры работают локально на фиксированных данных. [Передача владельцу на приёмку](../../docs/development/pr03-ux-handoff.md)
