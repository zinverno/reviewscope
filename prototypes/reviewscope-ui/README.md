# ReviewScope · интерактивный прототип

Откройте исходную фразу, проследите за одной проблемой в нескольких точках и проверьте, как получилась разница между периодами. На всех экранах используются синтетические отзывы.

## Локальный запуск

В рабочей копии PR #5 с Node.js 24 и npm выполните

```sh
cd prototypes/reviewscope-ui
npm ci
npm run dev
```

Откройте <http://127.0.0.1:5173/>. Vite слушает loopback. Если порт занят другим приложением, можно выбрать свободный через параметр `--port`.

## Девять шагов ручной приёмки

1. Откройте `#home` без прокрутки. Логотип, весь заголовок, описание и три карточки образуют первый экран. Между шапкой и надзаголовком — умеренный зазор, а не пустая полоса. На неподвижной главной частицы плавно пульсируют, центры не двигаются.
2. Наведите указатель на #02 или выберите карточку клавишей Tab. Номер и статус сменятся полной цитатой на той же площади. Посмотрите, видны ли точки за словами. Нажмите Escape, чтобы вернуть лицевую сторону.
3. Потяните #02 за середину цитаты. Участок видимого за стеклом поля меняется, линии следуют за границами. Отпустите карточку, затем щёлкните по ней. Откроется именно #02. Вернитесь кнопкой браузера. Начните новый перенос и нажмите Escape до отпускания, чтобы отменить его.
4. На телефоне коснитесь карточки один раз для чтения, второй раз для входа. Стрелка открывает отзыв сразу. Проведите пальцем по цитате для прокрутки страницы. Для переноса откройте «Действия с карточкой #01», выберите «Перемещение», подвиньте карточку за цитату или кнопками со стрелками и нажмите «Готово». Там же доступно «Сбросить расположение».
5. Медленно прокручивайте страницу. Сначала hero сохраняет положение (`HERO_HOLD`), затем те же точки за несколько кадров собираются в Евразию (`MORPH`). Остановитесь посреди перехода: геометрия должна остаться на месте. Сделайте 5–10 коротких реверсов у границ — без пружины, повторного создания поля и пропажи заголовка карты.
6. Дойдите до карты и прокрутите ещё немного: полный h2, управление, компании и краткий показатель остаются на месте в `ATLAS_HOLD`. Подождите 6–8 секунд: ореолы дышат, центры и текст неподвижны. Затем смените компанию и период, не уходя из сцены.
7. Выбирайте точки только по цветным частицам карты: «Арка», «Линия», «Мыс» и «Луч» доступны касанием, мышью и с клавиатуры (Tab, Enter/Space); отдельного диска у маркера нет. В «Одной точке» выберите «Арка» на сентябрь (2/3). В «Моей сети» раскройте состав «Вся сеть» (3/10) или отдельной точки и вернитесь кнопкой «← К итогу всей сети». У октябрьского «Мыса» три записи без текста и статус «Нет данных». В «Сравнении» выберите свою точку и «Луч», раскройте обе выборки.
8. Раскройте «Состав расчёта»: основания читаются обычной прокруткой в потоке под сценой, без вложенного scrollbox; выбор компании, режима и периода сохраняется. Вернитесь к карте и прокрутите дальше: в `RELEASE` собранная карта уходит по потоку без шва фона.
9. Под картой выберите «Проверить смысл» и оставьте сцену открытой. Шаг сохраняет выбор. Сопоставьте жалобу #02 с отрицанием #03. Через «Сравнить изменения» откройте два периода. В сентябре 3/6, в октябре 1/5, разница −30 п. п. Откройте исходные строки и вернитесь через Back. В исследовании проверьте отсутствие прямой связи #01–#03 и повтор текста #02–#05. Повторите маршрут с клавиатуры, при системном уменьшении движения и переключателем «Матовые панели» внизу страницы. Нативный zoom 200% и физический Firefox остаются отдельной ручной проверкой.

## Проверки и видеозапись

```sh
npm run lint
npm run typecheck
npm test
npm run build
npx playwright install --with-deps chromium firefox
npm run test:browser
BROWSER=firefox npm run test:browser
npm run capture:ux
```

Браузерные тесты запускают временный Vite-сервер. Для тестового Firefox задайте `BROWSER=firefox` и при необходимости `BROWSER_PATH` с путём к исполняемому файлу. После сборки команда `capture:ux` открывает локальный production preview, записывает один непрерывный проход фаз и отдельное раскрытие оснований, сохраняет кадры до/после, morph/ATLAS_HOLD, mobile/низкую высоту и профиль wheel-прокрутки. Выводится путь к каталогу с WebM, PNG, `frame-profile.json` и `verification.md`. Для своего пути передайте имя каталога через `npm run capture:ux -- <каталог>`, а для сравнения с предыдущей принятой версией — и каталог её сборки вторым аргументом.

В запуске **ReviewScope frontend** для PR #5 доступен архив **reviewscope-pr03-ux-v6**. Основной ролик `01-continuous-v6.webm` снят без склейки: первый кадр, `HERO_HOLD`, остановка в `MORPH`, две позиции `ATLAS_HOLD`, 6,8 секунды покоя, выбор компании/периода, `RELEASE`, третья сцена и обратный проход. `02-details-and-return.webm` показывает длинные основания и возврат. Кадры `before-hero-1920.png` / `after-hero-1920.png`, `morph-25.png`, `morph-50.png`, `morph-75.png`, `04-atlas-hold-a.png`, `05-atlas-hold-b.png`, `08-first-frame-1366.png`, `09-atlas-hold-1366.png`, `10-low-height-flow.png`, `12-mobile-hero.png` и `14-mobile-map.png` дополняют запись. В `frame-profile.json` замерен зазор шапки: 318 px до версии `08e7d0e` и 54 px после; на 1920×1080 заголовок и карточки помещаются в первый экран, карта полностью входит в stage. Нативный zoom 200% headless-средой не проверен. [Проверки и вложения PR #5](https://github.com/zinverno/reviewscope/pull/5/checks)

## Данные и геометрия

- [Исследование](src/fixture.ts) содержит 12 отзывов. Каждый ID с текстом входит в знаменатель один раз. #02 и #05 имеют разные ID с одинаковым текстом. В числитель входят жалобы на выдачу. Отрицания, неопределённость и жалобы на приготовление остаются в знаменателе. Пустая запись показана отдельно. [Правило подсчёта](src/analysis.ts)
- [Снимки четырёх вымышленных точек](src/network.ts) отделены от исследования. Сеть объединяет записи трёх собственных точек. «Луч» участвует в сравнении. Маркеры и состав расчёта используют один выбор.
- [Локальный контур Евразии](src/eurasia.svg) получен из Natural Earth 1:110m v5.1.2. Контур определяет центры кругов. Их положение на карте и положение маркеров вычисляются в одной проекции с общим кадром `mapFrame`. [Растровый рисунок поля](src/pointTexture.ts) задаёт регулярную hero-сетку, целые ядра и мягкий ореол; те же частицы собираются в карту и окрашиваются для выбранных точек. Геометрия и шрифты доступны офлайн. [Исходные полигоны](https://github.com/nvkelso/natural-earth-vector/blob/v5.1.2/geojson/ne_110m_admin_0_countries.geojson) · [Условия использования](https://www.naturalearthdata.com/about/terms-of-use/)
- Смена лиц реализована средствами HTML и CSS по визуальному референсу владельца. [Карточка gharsh11032000 на Uiverse](https://uiverse.io/gharsh11032000/tricky-cheetah-78)

Импорт, клиентский отчёт и PDF показывают будущие состояния. Вычисления и примеры работают локально на фиксированных данных. [Передача владельцу на приёмку](../../docs/development/pr03-ux-handoff.md)
