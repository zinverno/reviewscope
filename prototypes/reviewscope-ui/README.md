# ReviewScope · интерактивный прототип

Откройте отзыв, выберите точку на карте и проверьте, из каких исходных фраз складывается изменение доли жалоб на выдачу готового заказа. Три сцены работают локально на синтетических данных.

## Запуск

Из рабочей копии PR #5, с Node.js 24 и npm:

```sh
cd prototypes/reviewscope-ui
npm ci
npm run dev
```

Откройте <http://127.0.0.1:5173/>. Vite слушает loopback. Команда завершается с сообщением, если порт уже занят. Проверено с Node 24.14.1 и npm 11.11.0.

## Семь шагов для ручной приёмки

1. На главной наведите на #01, затем на #03. Сначала видны ID, дата и позиция. При раскрытии прочитайте исходную фразу. На телефоне коснитесь заголовка. Повторное нажатие закрывает карточку.
2. Потяните #02 за ручку с точками. Проследите за двумя линиями, отпустите, затем нажмите «Разобрать отзыв». Вы попадёте в #02. Вернитесь кнопкой браузера. Нажатие на ручку открывает кнопки перемещения. «Сбросить расположение» возвращает все три карточки.
3. Прокрутите до Евразии. В «Одной точке» выберите «Арка» на карте или в списке. Сентябрь даёт 2/3. В «Моей сети» выберите «Вся сеть», раскройте состав 3/10. Для октябрьского «Мыса» все три записи без текста, поэтому видна надпись «Нет данных».
4. В «Сравнении» выберите свою точку и «Луч» другой компании. У сторон одна проблема и период. Нажимайте на показатели, чтобы проверить состав каждой стороны. Тексты остаются в панели карты.
5. Перейдите к трём шагам под картой. Нажмите «Повторить», затем выберите «Проверить смысл», пока движется указатель. Выбор остаётся за вами. Tab и Enter также позволяют прочитать каждый шаг. При уменьшении движения проходите шаги вручную.
6. В третьем шаге нажмите «Открыть изменения». Переключите сентябрь (3/6) на октябрь (1/5). Откройте строку, задайте фильтр или выберите другую пару. Перейдите в «Отчёт» и вернитесь через Back. Проверьте период, выбранный отзыв, фильтр, пару и положение страницы.
7. В исследовании проверьте #02–#03 (общая тема и отрицание), #01–#03 (нет прямого ребра) и #02–#05 (повтор текста). Проверьте на телефоне меню и прокрутку по тексту, в Firefox — клавиатуру, масштаб 200% и переключатель «Матовые панели» внизу страницы.

## Проверки

```sh
npm run lint
npm run typecheck
npm test
npm run build
```

Браузерные регрессии запускают собственный временный Vite-сервер. При первой установке нужен браузер Playwright. Команды для Chromium:

```sh
npx playwright install chromium
npm run test:browser
```

Для Firefox установите соответствующую сборку Playwright и задайте `BROWSER=firefox`. Для уже установленного тестового Firefox поддерживается `BROWSER_PATH` с путём к исполняемому файлу. [Отдельный frontend workflow](../../.github/workflows/prototype.yml)

## Откуда берутся данные

- [Исследование](src/fixture.ts) содержит прежние 12 записей. Каждый ID учитывается один раз. Дословное совпадение #02 и #05 сохраняет два ID. Жалобы на приготовление, отрицания и неопределённость входят только в знаменатель текстовых отзывов. Пустой текст показан отдельно. Сентябрь и октябрь дают изменение −30 п. п. [Правило подсчёта](src/analysis.ts)
- [Карта](src/network.ts) использует отдельные снимки четырёх вымышленных точек. Сетевая доля вычисляется по объединению записей трёх собственных точек. «Луч» участвует только в сравнении. Список, маркеры и панель состава относятся к одному выбору.
- [Геометрия Евразии](public/eurasia.svg) основана на Natural Earth 1:110m v5.1.2. Метки спроецированы из демонстрационных координат в тот же viewBox. Тайлы и шрифты из сети не запрашиваются. [Полигоны Natural Earth](https://github.com/nvkelso/natural-earth-vector/blob/v5.1.2/geojson/ne_110m_admin_0_countries.geojson) · [Условия использования](https://www.naturalearthdata.com/about/terms-of-use/)
- Механики раскрытия и указателя реализованы для ReviewScope на Pointer Events, CSS и HTML. Визуальные референсы владельца — [карточка gharsh11032000](https://uiverse.io/gharsh11032000/tricky-cheetah-78) и [указатель Darlley](https://uiverse.io/Darlley/lazy-seahorse-31).

Импорт и клиентский отчёт показывают будущие рабочие состояния. Реальные файлы, сервер, аналитическое ядро, ML и экспорт PDF к прототипу не подключены. [Передача на приёмку](../../docs/development/pr03-ux-handoff.md)
