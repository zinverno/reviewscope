# PR-03 · UX v8

**NEEDS_OWNER_UX_APPROVAL**. Основа для сравнения в Draft PR #5 — v7, `bfbeed13717d7760205340c56453f1851ac70ffc`. [Запуск прототипа и сценарий проверки](../../prototypes/reviewscope-ui/README.md)

Откройте первый экран. Середина поля за отзывами сохраняет ровный шаг, у края точки редеют. Прокрутите до карты и остановитесь, когда буквы ещё в пути. Короткий обратный ход возвращает каждую букву и частицу по прежней траектории. Дальше на карте выберите компанию и проверьте её показатель. Для октябрьского «Мыса» доступны три записи без текста. В сравнении «Состав расчёта» содержит обе стороны.

Продолжите прокрутку до метода. Буквы собираются в заголовок «От фразы — к проверяемому изменению.», а точки занимают края трёх стёкол. На ширине 1000 px переключите первый шаг на «Проверить смысл» и проследите за нижним скруглением панелей при изменении высоты. На узком экране, при малой высоте и при уменьшенном движении заголовки читаются в обычном потоке.
