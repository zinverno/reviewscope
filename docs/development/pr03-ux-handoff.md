# PR-03 · UX v10

**NEEDS_OWNER_UX_APPROVAL**. Основа для сравнения в Draft PR #5 — v9, `bf3c3e0abb2eaf6589e463f19d7aab255b18e6bd`. [Запуск прототипа и сценарий проверки](../../prototypes/reviewscope-ui/README.md)

Откройте первый экран. Поле немного шире и выше. На восемь секунд оставьте страницу в покое. За карточками точки медленно отклоняются от базовых координат. Плотность плавно уменьшается к неровному краю. Прокрутите до карты и остановитесь, когда буквы ещё в пути. Короткий обратный ход возвращает каждую букву и частицу по прежней траектории. На карте понаблюдайте восемь секунд за разными фазами свечения неподвижных точек. Затем выберите компанию и проверьте её показатель. Для октябрьского «Мыса» доступны три записи без текста. В сравнении «Состав расчёта» содержит обе стороны.

Продолжите прокрутку до метода. Буквы собираются в заголовок «От фразы — к проверяемому изменению.», а точки занимают края трёх стёкол. Номер и название находятся по центру каждой карточки. Наведите на «Проверить смысл». Название уступает место цитатам, пояснению и действию, а светящийся край остаётся на месте. Tab тоже показывает оборот, Enter открывает отзыв #02. На сенсорном экране для чтения достаточно одного касания, повторное открывает ссылку. На узком экране, при малой высоте и при уменьшенном движении заголовки читаются в обычном потоке.
