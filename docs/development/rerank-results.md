# PR-21 · Результаты локального сравнения

**BASELINE_RETAINED · SYNTHETIC_EVIDENCE_ONLY.** Для запроса-формулировки mMARCO поднял macro nDCG@5 MiniLM hybrid с 0,395 до 0,461 на тех же кандидатах. Для запроса-примера результат вырос с 0,368 до 0,372. Порог +0,05 в каждом режиме не пройден. Примеры по двум согласованным аспектам ухудшились. Default остаётся прежним.

110 авторских синтетических отзывов, по 55 на dev и test, по 12 запросов на split. Всего 1 320 размеченных пар, неизвестных 0. Для каждого показателя test доступны 6 запросов-формулировок и 6 запросов-примеров. Корпусы индексировались независимо. Точные позиции anchor/context совпали у всех фрагментных методов в каждом split. Настройки после freeze не подбирались. Старые fixtures служат регрессией. Шесть аспектов одного автора дают описательную парную оценку. Независимые реальные метки отсутствуют.

Платных запросов 0. Все inference-фазы прошли с одним CPU-потоком и без внешнего сетевого интерфейса. Загрузка весов была отдельной. Размер двух подготовленных наборов файлов — 975402518 байт. MiniLM уже находился в локальном Hub cache. Cold означает новый процесс с возможным тёплым файловым кэшем ОС. В матрице отдельно приведены построение индекса, токенизация, плотное кодирование, поиск, слияние и повторное ранжирование с уже загруженной моделью. Показатели RSS получены опросом каждые 50 мс. Они характеризуют конкретный хост.

Разнообразный stress включал 10 000 версий, 2 471 557 байт, 20 126 разных anchor и 280 147 входных токенов.
