# Карточка утверждения срока хранения

Одна карточка на источник и класс. Начальное значение каждого решения — **unset**.

| Поле | Заполняет владелец с оператором |
| --- | --- |
| Workspace, project, source, класс | UUID области; raw, configuration, positions, versions, snapshot, temporary, derivatives, report_export, diagnostics или backup |
| Место обработки и основание | Ссылка на закрытое подтверждение полномочий оператора, договор, применимую юрисдикцию, место основного и резервного хранения |
| Право на операции | Получение, хранение текста/ID/URL, анализ, передача владельцу, получатели, удаление |
| Якорь и срок | received — подтверждённое получение, registered — регистрация связанной поставки, created — создание соответствующей версии, снимка или результата. Число дней и последствия неизвестного времени |
| Пересмотр и исключение | Период пересмотра в днях, ответственный owner, отдельное подтверждение удержания и условия снятия |
| Резервные копии | Хранитель, все хранилища, WAL, реплики, поколения и immutable-копии; отсчёт, максимальный срок ухода, плановая и наблюдаемая даты |
| Журналы и внешние копии | Настройки уровня PostgreSQL, bind-параметров, HTTP/proxy, трассировки, дампов процесса и сроков на этом хосте; место передачи скачанного файла |
| Решение | Разрешено для данного источника после проверки, или BLOCKED_RETENTION_POLICY. UUID подтверждения вместо текста договора передаётся в API |

Локальный PUT `/api/v1/workspaces/{w}/sources/{s}/retention` принимает `data_class, authority_ref, anchor, days, review_days, hold_ref`. Отсутствие hold передаётся как JSON null. Решение применяется к доставленным объектам источника. При отдельных несогласованных сроках исходника и производных владелец видит необходимость пересмотра связанного набора. Копии, исключения и реальные даты ухода из backup фиксируются в закрытом реестре оператора.
