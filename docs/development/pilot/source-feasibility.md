# Из какого источника брать два периода

**Первый кандидат — обратная связь, которую клиент уже собирает сам.** Попросить аналитика повторить выгрузку из той же формы или CRM, из которой он готовил последний отчёт. Для российского пилота есть конкретный пример с документированной процедурой — Яндекс Формы. Перед получением файлов нужно подтвердить происхождение данных, полномочия агентства и условия анализа у подрядчика.

Все ссылки в матрице — официальные источники, проверены **20.11.2026**. Статус относится к указанной возможности. `CONFIRMED_BY_DOCS` означает, что процедура или поле описаны. Доступ к аккаунту, две фактические выгрузки и право на клиентский отчёт проверяются отдельно.

Наличие URL в файле не обещано. [Экспорт](https://yandex.ru/support/forms/ru/answers) · [Роли](https://yandex.ru/support/forms/ru/access) | Можно повторно выбрать период. Охват ограничен ответами этой формы и фильтром, удалённые ответы исчезают из обычной выгрузки. Сверить число строк в таблице за период и в файле. Устойчивость ID между экспортами и доступность старых редакций проверить у владельца. | Владелец подтверждает основание сбора, локальный анализ, допустимые выдержки, получателя и срок хранения. Стандарты описывают только формат. [CSV](https://www.rfc-editor.org/rfc/rfc4180) · [JSON](https://www.rfc-editor.org/rfc/rfc8259) | Нужны исходные фильтры, счётчик до экспорта и второй независимо полученный файл. Сохранить инструкцию выгрузки. До сверки неизвестны полнота, возможность повтора, устойчивость ID и история редакций. | Запросить основание по всей цепочке «источник → клиент → агентство → исполнитель» отдельно для хранения, анализа, клиентских цитат и передачи. Если остаются персональные данные, оператор проверяет основание для поручения обработки и его условия. Для сторонней площадки также действуют ограничения источника. Автор может исправить отзыв. Повторное открытие кабинета не воспроизводит прежний снимок. Экспорт полного корпуса, история изменений и стабильный ID для сопоставления не подтверждены. | Условия описывают использование материалов сервисом, в том числе через виджеты. Основание для хранения двух выгрузок, передачи подрядчику и цитирования в отчёте отдельно не установлено. [Условия Яндекс Бизнеса](https://yandex.ru/legal/clients_termsofuse/ru/) | Цена и доступность разрешённого экспорта неизвестны. Кабинет — `CONFIRMED_BY_DOCS`, источник файла — `NEEDS_ACCOUNT_TEST`. |
| **2ГИС Places API.** Ключ для разработчика, демодоступ или подписка. | Объект организации и `items.reviews` со статистикой, в том числе рейтингом и количеством отзывов. В проверенной схеме нет списка отдельных отзывов с текстом, звёздами, датой, ID и ссылкой. [Схема Places](https://docs.2gis.com/en/api/search/places/reference/3.0/items) · [Доступ](https://docs.2gis.com/en/api/search/places/overview) | Повторный запрос объекта может дать новое агрегированное значение. Полнота текстового корпуса, версии отдельных отзывов и сравнение по их ID здесь неприменимы. | Условия использования данных объекта зависят от доступа. Для хранения, цитирования или передачи текстов данный метод основания не даёт. | Цена подписки для участника неизвестна. Статистика — `CONFIRMED_BY_DOCS`. Страница продукта не специфицирует API или состав файла. Полный текст, звёзды, дата, ID исходной площадки, ссылка на отзыв и разделение площадок требуют проверки образца. [Описание тарифа](https://reklama.2gis.ru/promotion/reviewpro-mashtab) | Проверить глубину истории, фильтры точек и площадок, повтор через месяц, неизменность ID и видимость редакций. В самом 2ГИС после правки показывается дата изменения. Это может сдвигать отзыв между месяцами. [Правка отзыва](https://help.2gis.ru/question/kak-ostavit-svoy-otzyv-k-kompanii/) | Сублицензия регулирует доступ к ПО и ограничивает передачу прав на него третьим лицам. Возможность хранить выгрузку, повторно анализировать и передавать тексты подрядчику или цитировать их в отчёте нужно проверить по договору, включая исходные площадки. | Подключение по договору, условия зависят от тарифа и числа локаций. ID пригоден для проверки сопоставления, его сохранность на двух реальных датах не проверена. | Политика ограничивает использование контента вне GBP-проекта. [Content storage](https://developers.google.com/my-business/content/policies) | API бесплатен для зарегистрированных пользователей, требуется одобрение. Метод — `CONFIRMED_BY_DOCS`. **Решение для пилота.** Начать с имеющейся у агентства первичной обратной связи. Запросить сведения об источнике и правах до файлов. Если доступен только кабинет с выборкой или не разрешена передача текста, зафиксировать ограничение и выбрать другой источник. Критерии допуска двух снимков — в [контракте данных](data-contract.md), фактическое состояние — в [статусе](status.md).
