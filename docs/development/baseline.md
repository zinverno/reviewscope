Стартовая проверка останавливает приложение при недостающих векторах. Загрузка файлов отсутствует, дисковый кэш Discover принудительно выключен, приложение разметки останавливается до записи. |

### Штатный локальный запуск

Из корня проекта, в подготовленном окружении Python ≥3.12. Для вычисления новых векторов нужен extra `embeddings`, для проверок — `dev`. Полная локальная установка описана как `pip install -e ".[dev,embeddings]"`. Для демо с готовыми векторами предусмотрен `requirements.txt`. [Конфигурация пакета](../../pyproject.toml) · [Режимы запуска](../DEPLOYMENT.md)

| Команда | Результат и предпосылка |
| --- | --- |
| `streamlit run app.py` | Локальная аналитика по существующему файлу. Путь по умолчанию — `data/reviewscope.duckdb`. В чистой копии можно ввести путь к упакованной синтетической базе `demo/reviewscope_demo.duckdb`. |
| `RS_PUBLIC_DEMO=1 streamlit run app.py` | Демо с фиксированной базой и готовыми векторами. Эквивалентная настройка хоста — Streamlit secret `public_demo = "1"`. |
| `python scripts/generate_demo_data.py` | [Генератор](../../scripts/generate_demo_data.py) пишет синтетические CSV, JSON и метаданные в `data/`. Для появления локальной DuckDB нужен отдельный импорт. |
| `python scripts/validation_sample.py data/demo_reviews.csv --out-dir validation_data/demo` | Пример после генерации синтетики. [Скрипт](../../scripts/validation_sample.py) готовит `validation_data/demo/dataset.duckdb`, оценки и очередь разметки. |
| `streamlit run app_labeling.py` | Локальная разметка подготовленной очереди. После закрытия пакета доступны Markdown/JSON с метриками детекторов. |

## Проверки базового коммита

Проверки выполнялись из отдельного worktree с пакетами имеющегося окружения. Python 3.14.7, pytest 9.1.1, Ruff 0.16.7. Для pytest исходники взяты из `src/` этой копии, использованы CPU и ранее кэшированная multilingual MiniLM. Переменные `HF_HUB_OFFLINE=1` и `TRANSFORMERS_OFFLINE=1` отключили скачивание модели. В [CI](../../.github/workflows/ci.yml) указан Python 3.12.

## Что переносим в следующие этапы

- **PR-09–10 и 13.** В JSON-адаптере элементы неподходящего типа удаляются до подсчёта входных строк, а повтор `id`/`review_id` может отсеяться до нормализации. Data Quality видит лишь сохранённые строки. Чтобы утверждать полноту, понадобится сверка с исходной выгрузкой. [Адаптер](../../src/reviewscope/ingestion/json_adapter.py) · [Data Quality](../../src/reviewscope/ui/data_quality.py)
- **PR-04–06 и 19–24.** В ключе кэша есть имя модели и хэш приведённого к нижнему регистру обрезанного по краям текста. Версия определения проблемы, версия модели решений и границы фрагмента ещё не представлены. Номер темы и звёзды отзыва недостаточны для повторного подсчёта жалоб на конкретную проблему. [Отпечаток](../../src/reviewscope/models/review.py) · [Темы](../../src/reviewscope/analysis/topics.py) · [Разбиение слов по звёздам](../../src/reviewscope/analysis/keywords.py)
- **PR-07–12 и 26–33.** Обновление по `review_id` и отпечаток набора в контуре разметки не образуют историю клиентских снимков. Потребуются изоляция клиента, сроки хранения и удаления, сохранённое определение, сравнение периодов и клиентский отчёт. [Запись отзывов](../../src/reviewscope/storage/duckdb_store.py) · [Контроль набора для разметки](../../src/reviewscope/validation/scoring.py)
